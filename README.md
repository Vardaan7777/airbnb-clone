# Airbnb Clone

A web app for listing and managing stays, built while learning full stack development.

## Features
- Create, view, edit, and delete listings (CRUD)

## Tech Stack
- Node.js
- Express
- MongoDB and Mongoose
- EJS

## How to Run
1. Clone the repo
2. Run `npm install`
3. Start MongoDB locally
4. Run `node app.js`
5. Open `http://localhost:8080`
